# Protocol

## 1. Question

Among adults presenting to the emergency department with suspected acute coronary
syndrome, how accurately does high-sensitivity troponin I diagnose myocardial
infarction compared with adjudicated final diagnosis?

## 2. Question Framework

Framework: PICO, used here with a diagnostic-accuracy appraisal plan.

| Element | Definition |
|---|---|
| Population | Adults presenting to the emergency department with suspected acute coronary syndrome |
| Intervention / index test | High-sensitivity troponin I |
| Comparator / reference standard | Adjudicated final diagnosis of myocardial infarction |
| Outcome | Diagnostic accuracy: sensitivity, specificity, and classification errors |

## 3. Inclusion Criteria

| ID | Criterion |
|---|---|
| I1 | Adult emergency-department population with suspected acute coronary syndrome |
| I2 | Evaluates high-sensitivity troponin I as an index test |
| I3 | Reports a reference standard for myocardial infarction diagnosis |
| I4 | Reports enough data for diagnostic accuracy extraction |

## 4. Exclusion Criteria

| ID | Criterion |
|---|---|
| E1 | Pediatric-only population |
| E2 | No reference standard |
| E3 | Editorial, narrative review, case report, or abstract-only record |

## 5. Planned Appraisal

Diagnostic-accuracy studies will use QUADAS-2. Appraisals are project-scoped and
will be stored under `data/papers/appraisals/diagnostic-demo/`.
