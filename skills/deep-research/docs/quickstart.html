Start here

Initialize a standalone research repo, then add projects, papers, and runs.

Standalone repo mode is the default path when you do not want generated wiki-manager output.

Create A Repo

/deep-research:init ~/research/my-manuscript-repo
/deep-research:project create adolescent-cbt --repo ~/research/my-manuscript-repo

Add Papers Manually

/deep-research:pool-add --repo ~/research/my-manuscript-repo --pmid 12345678

For a DOI, a PDF, a bulk .bib, or a folder of PDFs — none of which pool-add covers — call the registry script directly:

python3 scripts/registry.py add --repo ~/research/my-manuscript-repo --doi 10.1000/example
python3 scripts/registry.py add-pdf --repo ~/research/my-manuscript-repo --file paper.pdf
python3 scripts/registry.py import-bib --repo ~/research/my-manuscript-repo --file refs.bib
python3 scripts/registry.py import-folder --repo ~/research/my-manuscript-repo --dir papers/ --recursive

Summarize One Paper

/deep-research:summarize \
  --repo ~/research/my-manuscript-repo \
  --project adolescent-cbt \
  --pmid 12345678 \
  --purpose journal-club \
  --format both

Single-paper summaries appraise by default when full text and a supported appraisal framework are available.

Summarize Several Papers

/deep-research:summarize-set \
  --repo ~/research/my-manuscript-repo \
  --project adolescent-cbt \
  --pmid 12345678 \
  --pmid 23456789 \
  --overview \
  --format both

Run A Full Review

Ask the agent for a literature review or evidence synthesis. It will configure Stage 0, confirm the profile and target root, then run the Stage 0-8 workflow.

Agent harnesses such as Claude Code or Codex should run the deterministic scripts, inspect returned JSON status, dispatch extraction/appraisal/summary work only when requested by that status, then rerun the command to resume.
