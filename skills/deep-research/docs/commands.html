Slash commands

Use the slash commands for the everyday cases; drop to the raw scripts for everything they don't cover.

Each /deep-research:* command calls one script directly, with no Stage 0-8 negotiation, and prints the script's own JSON output. Agent harnesses should read status fields and resume by rerunning the same command after required files are written.

Repo And Project

/deep-research:init <path>
/deep-research:init <path> --from-wiki <wiki-root>
/deep-research:project create <slug> --repo <path>
/deep-research:project list --repo <path>

No wrapper for the wiki-export adapter — run it directly:

python3 scripts/research.py export wiki --repo <path> --wiki <wiki-root> --project <slug>

Registry Intake

/deep-research:pool-add --repo <path> --pmid <pmid>
/deep-research:pool-add --repo <path> --query "..." --n 10
/deep-research:pdf-lookup --repo <path> --evidence-id pmid:12345678
/deep-research:bib-export --repo <path> --out refs.bib --select all

No wrapper for a DOI-only add, PDF/bulk-bib/folder import, or the raw registry list/pool projection steps — run these directly:

python3 scripts/registry.py add --repo <path> --doi <doi>
python3 scripts/registry.py add-pdf --repo <path> --file <pdf>
python3 scripts/registry.py import-bib --repo <path> --file refs.bib
python3 scripts/registry.py import-folder --repo <path> --dir papers/ --recursive
python3 scripts/registry.py list --repo <path>
python3 scripts/registry.py pool --repo <path>

Pool Reuse

No slash-command wrapper yet — this is internal run plumbing, not a standalone ask:

python3 scripts/pool.py seed --run-dir <run> --repo <path> --query "..."
python3 scripts/pool.py lookup --repo <path> --pmid <pmid> --project <slug>
python3 scripts/pool.py reuse --run-dir <run> --repo <path> --pmid <pmid> --project <slug>
python3 scripts/registry.py promote --repo <path> --run-dir <run>
python3 scripts/registry.py appraise-promote --repo <path> --run-dir <run> --project <slug>

Paper Summaries

/deep-research:summarize --repo <path> --pmid <pmid> --project <slug> --format both
/deep-research:summarize --repo <path> --pdf paper.pdf --project <slug>
/deep-research:summarize-set --repo <path> --pmid 123 --pmid 456 --overview
/deep-research:summarize-set --repo <path> --topic "..." --limit 10 --select-only

Run Monitoring

/deep-research:status <run> --table
/deep-research:status <run> --missing
/deep-research:watch --run-dir <run> --once

Verification And Rendering

/deep-research:verify run --run-dir <run> --report <run>/outputs/report.md
/deep-research:verify single-paper-summary --summary <run>/workspace/summaries/pmid-123.json --run-dir <run>
/deep-research:verify paper-summary-set --summary-set <run>/workspace/summary-set.json --run-dir <run>

No wrapper for HTML/PDF/docx rendering — run these directly:

python3 scripts/html_report.py build --run-dir <run> --out <run>/outputs/report.html
python3 scripts/render.py all --run-dir <run> --formats pdf,docx
Full flag reference for a command: commands/<name>.md, or /deep-research:help. For a raw script: python3 scripts/<name>.py --help.
