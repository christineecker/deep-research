Scripts

Commands do deterministic state work; agents do extraction, appraisal, summary, and synthesis reasoning.

Most commands emit JSON. Agent harnesses should read status fields and resume by rerunning the same command after required files are written.

Repo And Project

python3 scripts/research.py init <path>
python3 scripts/research.py init <path> --from-wiki <wiki-root>
python3 scripts/research.py project create <slug> --repo <path>
python3 scripts/research.py project list --repo <path>
python3 scripts/research.py export wiki --repo <path> --wiki <wiki-root> --project <slug>

Registry Intake

python3 scripts/registry.py add --repo <path> --pmid <pmid>
python3 scripts/registry.py add --repo <path> --doi <doi>
python3 scripts/registry.py add-pdf --repo <path> --file <pdf>
python3 scripts/registry.py import-bib --repo <path> --file refs.bib
python3 scripts/registry.py import-folder --repo <path> --dir papers/ --recursive
python3 scripts/registry.py lookup --repo <path> --evidence-id pmid:12345678
python3 scripts/registry.py list --repo <path>
python3 scripts/registry.py pool --repo <path>

Pool Reuse

python3 scripts/pool.py seed --run-dir <run> --repo <path> --query "..."
python3 scripts/pool.py lookup --repo <path> --pmid <pmid> --project <slug>
python3 scripts/pool.py reuse --run-dir <run> --repo <path> --pmid <pmid> --project <slug>

python3 scripts/registry.py appraise-promote --repo <path> --run-dir <run> --project <slug>

Paper Summaries

python3 scripts/paper.py summarize --repo <path> --pmid <pmid> --project <slug> --format both
python3 scripts/paper.py summarize --repo <path> --pdf paper.pdf --project <slug>
python3 scripts/paper.py summarize-set --repo <path> --pmid 123 --pmid 456 --overview
python3 scripts/paper.py summarize-set --repo <path> --topic "..." --limit 10 --select-only

Verification And Rendering

python3 scripts/verify.py run --run-dir <run> --report <run>/outputs/report.md
python3 scripts/verify.py single-paper-summary --summary <run>/workspace/summaries/pmid-123.json --run-dir <run>
python3 scripts/verify.py paper-summary-set --summary-set <run>/workspace/summary-set.json --run-dir <run>
python3 scripts/html_report.py build --run-dir <run> --out <run>/outputs/report.html
python3 scripts/render.py all --run-dir <run> --formats pdf,docx
Run python3 scripts/<name>.py --help for exact parser options.
