Stage 0-8

The full pipeline is for literature reviews and evidence synthesis.

Profiles change breadth and gates, but every full run follows the same audited shape.

Stages

StageNamePurpose
0ConfigureQuestion, profile, target root, filters, outputs, connector preflight.
1ProtocolQuestion framework and numbered inclusion/exclusion criteria.
2SearchPool seeding plus orthogonal PubMed queries.
3ScreenDedupe and title/abstract triage.
4RetrieveOpen-access ladder, full-text acquisition, quarantine for missing text.
5ExtractOne structured extraction per paper with spans.
6AppraiseDesign-specific appraisal and outcome-level certainty inputs.
7SynthesizeEffect-direction synthesis, conflicts, gaps, hypotheses.
7bDigestShort digest of the completed report.
8PublishAssemble, verify, render, and promote or export.

Profiles

ProfileScopeTypical use
fastNarrowQuick field read, smaller article cap.
standardMediumDefault review path with protocol and strategy gates.
systematicWideDefensible review with dual screening and PRISMA log.
maxMaximumBroadest sweep, optional grey literature and extra connectors.

Stop After Extraction

Set pipeline.stop_after_stage: 5 to build the extracted-paper pool without appraisal, synthesis, or report generation. Later runs can reuse those canonical extractions.

Quarantine

When full text cannot be acquired, the run records missing papers and asks the user to supply PDFs in the run inbox. Abstract-only records remain labeled as such and cannot receive full-text appraisal.
