Lightweight profiles

Summarize one paper or a selected set without running a full review.

The summary profiles reuse the canonical registry, source store, extraction records, appraisals, and verifier.

Single-Paper Summary

python3 scripts/paper.py summarize --repo <repo> --pmid <pmid>
python3 scripts/paper.py summarize --repo <repo> --doi <doi>
python3 scripts/paper.py summarize --repo <repo> --pmcid <pmcid>
python3 scripts/paper.py summarize --repo <repo> --pdf paper.pdf
python3 scripts/paper.py summarize --repo <repo> --evidence-id pmid:12345678

Single-paper summaries include appraisal by default when full text is available and a supported framework applies. Use --no-appraise only for a deliberate extraction-only summary.

Selected-Paper Summary Set

python3 scripts/paper.py summarize-set --repo <repo> --pmid 123 --pmid 456
python3 scripts/paper.py summarize-set --repo <repo> --ids-file papers.txt
python3 scripts/paper.py summarize-set --repo <repo> --bib refs.bib
python3 scripts/paper.py summarize-set --repo <repo> --folder papers/ --recursive
python3 scripts/paper.py summarize-set --repo <repo> --question "..."
python3 scripts/paper.py summarize-set --repo <repo> --topic "..."

Set mode produces one verified paper summary per included paper, plus an optional bounded overview. Topic and question mode perform candidate discovery, not systematic retrieval.

Run Status

StatusAgent action
pending_retrievalAcquire source material or ask the user for missing files.
pending_extractionDispatch the extraction prompt for the target paper.
pending_appraisalDispatch the appraisal prompt for the verified extraction.
pending_summaryDispatch the paper-summary prompt or assemble summary JSON.
completedRead the rendered Markdown/HTML outputs.

Output Sections

A single-paper summary includes citation, bottom line, reason for summary, design and evidence basis, population and setting, intervention/exposure/test/model, comparator, outcomes, appraisal, limitations, practical takeaways, what not to conclude, and provenance.

Set overviews may compare descriptive attributes across included papers. They must not claim pooled effects, certainty of a body of evidence, or consensus unless a full review produced those artifacts.
