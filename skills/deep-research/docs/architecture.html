Standalone mode

The repo is the source of truth for papers, sources, extractions, appraisals, projects, and exports.

It does not require wiki-manager. Wiki import and export are compatibility bridges only.

Layout

<repo>/
  data/
    sources/
      assets/            hash-named PDFs
      sources/           evidence-kernel snapshots
      events.jsonl       retrieval log
    papers/
      registry.jsonl     canonical paper registry
      pool.jsonl         regenerated view, not hand-edited
      extractions/       canonical Stage 5 records
      appraisals/
        <project>/       project-scoped appraisal records
  projects/<slug>/       protocol, synthesis, manuscript, refs, figures, tables
  runs/<slug>/           run-local config, corpus, workspace, outputs
  templates/
  exports/

Where Data Lives

ArtifactLocationNotes
Paper metadatadata/papers/registry.jsonlCanonical one-record-per-paper registry.
PDFsdata/sources/assets/Content-addressed by sha256.
Source snapshotsdata/sources/snapshots/Write-once text snapshots used by spans; legacy reads may fall back to data/sources/sources/.
Extractionsdata/papers/extractions/Reusable across runs and projects.
Appraisalsdata/papers/appraisals/<project>/Scoped to the project question.
Run outputsruns/<slug>/outputs/Reports, summaries, verification output.
Manuscriptsprojects/<slug>/Project-owned writing and export inputs.

Reuse Rule

New runs should seed from the registry, reuse verified extractions when available, and promote newly verified extractions back to the canonical store. Appraisals are reused only for the same project because risk-of-bias and certainty depend on the review question.
