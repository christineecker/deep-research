Glossary

GateA checkpoint where the pipeline shows work back to the user and waits for approval before continuing (e.g. protocol+strategy gate before Stage 2).
PoolCross-run shared store of already-extracted/appraised papers, so later runs reuse instead of re-processing (pool.py reuse/sync).
stop_after_stageConfig field to halt a run after Stage 5 (pool-building only, no appraisal/report). Resumable later.
QuarantinePapers whose full text couldn't be acquired through the retrieval ladder; logged to missing.md, handed back to the user.
FrameworkPICO/PECO (default) or PEO/PCC/SPIDER/SPICE — the structure used to restate the question before anything runs.
